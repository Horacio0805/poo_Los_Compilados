## Descripción

Este repositorio contiene el proyecto desarrollado para la materia de **Programación Orientada a Objetos (POO)**.

El objetivo principal del proyecto es aplicar los conceptos fundamentales de la programación orientada a objetos mediante el desarrollo de una aplicación estructurada, modular y fácil de mantener.

Durante el desarrollo se ponen en práctica conceptos como:

* Clases y objetos
* Atributos y métodos
* Encapsulamiento
* Herencia
* Polimorfismo
* Abstracción
* Constructores
* Métodos de acceso (`getters` y `setters`)
* Relaciones entre clases

## Objetivo

Desarrollar una aplicación que permita demostrar los conocimientos adquiridos durante el curso de Programación Orientada a Objetos, aplicando buenas prácticas de programación y una estructura organizada.

## Conceptos de POO aplicados

### Encapsulamiento

Se utilizan modificadores de acceso para proteger los atributos de las clases y controlar la forma en que se accede a ellos.

### Herencia

Se implementan relaciones entre clases para permitir la reutilización de atributos y métodos.

### Polimorfismo

Se permite que diferentes objetos respondan de distintas maneras ante una misma operación.

### Abstracción

Se representan únicamente las características y comportamientos relevantes de cada objeto.
